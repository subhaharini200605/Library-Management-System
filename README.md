Library Management System

Description

This is a simple Library Management System developed using C programming language.

The program helps to manage books in a library. It uses structures, functions, arrays, pointers, and switch-case statements.

Features

- Add a new book
- Search for a book using Book ID
- Issue a book
- Return a book
- Display all books
- Check book availability

Technologies Used

- C Programming Language
- Structures
- Arrays
- Functions
- Pointers
- Switch Case

Book Details

Each book contains:

- Book ID
- Book Title
- Availability Status

Menu Options

1. Add Book
2. Search Book
3. Issue Book
4. Return Book
5. Display Books
6. Exit

How to Run

1. Compile the C program using a C compiler.
2. Run the executable file.
3. Select an option from the menu.
4. Enter the required book details.
5. Perform library operations.
